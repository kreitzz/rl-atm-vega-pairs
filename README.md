# Reinforcement learning for options relative value

[Strategy-economics research extension](reports/strategy_economics/report.md):
explains the short-straddle option/hedge P&L, retrospective IV–RV and price-path
splits, and one exploratory risk-cut trial. Includes an [illustrated version](reports/strategy_economics/index.html)
and [offline reproduction instructions](reports/strategy_economics/README.md).
The original paper and strategy below are unchanged.

Short-term 25-delta put pairs, initially vega neutral and delta hedged daily. A frozen spread signal proposes trades; a contextual learner selects 50%, 75% or 100% vega exposure using monthly fits on completed past outcomes. The retained learner uses direct Sharpe optimization, not Q-learning.

## Original put-pair study

**Validation-selected filtered strategy:** RL achieves **0.573 versus 0.478** excess Sharpe at fixed full sizing in 2018–2021 validation, and **1.263 versus 1.055** in January 2022–August 2025 evaluation. All these comparisons use $10m funded accounts. Evaluation profit above cash is $248,673 versus $200,853. Selection ranks 33 archived screened configurations using only validation scores; the selected 27-input, 18-month, 50/75/100% policy keeps the profitability filter. Archived selection scores use the original $345m research account. This is a retrospective split within an inherited strategy and universe, not an untouched holdout.

[Additive sizing experiment](reports/p25_additive_sizing/Findings.txt): 270 monthly fits compare a linear score, smooth one-variable effects, and those effects plus three predefined interactions, using the same 608 proposals and 50/75/100% sizing ladder. Later Sharpe is 0.931, 1.060 and 0.944 respectively, versus 1.263 for the original tree/CEM. Nonlinear main effects improve the point estimate over linear scoring; interactions help earlier but hurt later. Both matched comparisons' later paired intervals include zero. This tests a new score-to-size pipeline, not additive functions under the original CEM objective; no replacement is promoted. [Chart](reports/p25_additive_sizing/comparison.png) · [Frozen protocol](reports/p25_additive_sizing/protocol.json) · [Verification](reports/p25_additive_sizing/verification.json). [Matched-objective direct sizing](reports/p25_direct_policy/Findings.txt): linear and additive policies optimize the same daily shadow-path Sharpe as tree/CEM, with the same 50/75/100% actions and 9,600 candidate evaluations per monthly fit. The experiment saves 180 primary models and 24 training-only seed checks, and exactly reproduces all 90 original tree/CEM choices. Later Sharpe is 0.873 for direct linear and 1.013 for direct additive, versus 1.263 for tree/CEM; earlier Sharpe is also lower. Later paired intervals favor the tree over direct linear, while the additive comparison includes zero. Gaussian coefficient search and categorical leaf search differ in capacity and optimization geometry; these results do not establish that every additive policy is inferior. [Chart](reports/p25_direct_policy/comparison.png) · [Protocol](reports/p25_direct_policy/protocol.json) · [Verification](reports/p25_direct_policy/verification.json). [Frozen-policy generalization diagnostic](reports/p25_generalization_bridge/Findings.txt): all 608 proposals' old-cost standalone paths reconstruct exactly at the archive's stored precision. Crossed admission masks show an interaction between sizing and the selected portfolio; this is not simply a commission effect or proof of additive overfitting. Additive-versus-tree intervals still span zero. No models or trading decisions changed.
