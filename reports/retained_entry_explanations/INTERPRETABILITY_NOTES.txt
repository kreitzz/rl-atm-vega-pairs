INTERPRETABILITY FOR THE RETAINED IMPLEMENTATION

There are three distinct questions: why was a proposal eligible, why did the learner assign this size, and why did the funded simulator admit or reject it? The new audit explains size exactly and retains the saved admission status; it does not replace the eligibility specification.

Put pairs: follow the exact observed root-to-leaf conditions, then read the selected sizing action for that leaf. Completed profitability memory, IV, return correlation and execution cost appear frequently. These are local decision rules; there is no universal rule that increasing one input must increase size.

Straddles: standardized inputs and ridge coefficients add exactly to a context score. Score thresholds assign a context, then the learned context-to-size map assigns 50/75/100%. The score is a completed-trade dollar-profit partition target, not itself a Q-value. Size maps need not be monotonic because the subsequent objective is aggregate daily Sharpe.

Setting IV to its monthly training center changes 36.6% of fitted later-period proposal sizes; VIX change changes 15.3%, normalized RV-minus-IV memory 12.9%, and VIX level 11.9%. These are conditional sensitivity measures across all proposals, including rejected ones, not estimated causal effects.

608 put-pair sizes and 35774 straddle sizes reproduce the saved policy levels exactly. Models are checked for completed outcomes before the monthly fit cutoff. Some early months use a default action and have no fitted feature attribution.

The two importance charts intentionally use different definitions. Tree node usage and a ridge-score centering ablation should not be compared numerically as the same importance scale.

Examples are the earliest executed entry of each size in each reporting period, selected without looking at their profit. Full rule paths, scores, size maps and admission statuses are in the accompanying CSVs.

This adds decision transparency. It does not by itself establish an out-of-sample sizing advantage, causal explanations, execution feasibility or conference readiness. Stability tests and new forward evaluation remain useful.
